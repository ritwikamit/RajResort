# Image Asset Plan

## Request from the resort
- Logo (SVG preferred; transparent PNG acceptable).
- Landscape exterior/entrance hero image.
- Rooms, bathrooms, reception/common areas.
- Banquet/event spaces and real setup examples if offered.
- Dining/food only if current food service is confirmed.
- Facilities such as parking/garden only if they exist and should be advertised.

## Suggested structure
`public/images/raj-resort/` with `logo.svg`, `hero-exterior.webp`, and subfolders `rooms/`, `events/`, `facilities/`, `gallery/`.

## Rights and authenticity
Request original files or written permission. Do not hotlink or copy photos from Justdial, MakeMyTrip, Agoda, Facebook or Instagram without permission. Do not present stock/AI imagery as the actual property. Obtain consent for identifiable guests and children. Keep source originals and permission records.

## Optimization
Create WebP/AVIF derivatives, preserve the main subject in mobile crops, avoid edits that misrepresent the property, use accurate alt text, and lazy-load gallery images below the fold.
