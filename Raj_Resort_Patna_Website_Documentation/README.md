# Raj Resort Patna – Website Documentation Pack

This pack is a research-backed starting point for a responsive official resort website.

## Included
- `01-PRD.md` – product goals, scope and acceptance criteria
- `02-TRD.md` – architecture, stack, routes and integrations
- `03-DESIGN-SYSTEM.md` – visual system and glassmorphism guidance
- `04-UI-UX-SPEC.md` – page structure and user flows
- `05-CONTENT-AND-SEO.md` – content and local SEO plan
- `06-SECURITY-PRIVACY.md` – security and privacy controls
- `07-QA-AND-BUG-FIXES.md` – test and launch checklist
- `08-RESEARCH-AND-REFERENCES.md` – findings, links and caveats
- `09-OWNER-QUESTIONNAIRE.md` – owner confirmations needed
- `assets/image-guidance/IMAGE-ASSET-PLAN.md` – photography plan

## Booking links must be kept separate
Create a dedicated **Book a Stay** section containing only these provider links:
- MakeMyTrip: https://www.makemytrip.com/hotels/raj_resort-details-patna.html
- Agoda: https://www.agoda.com/en-in/raj-resort-h61899892/hotel/patna-in.html?cid=1844104&ds=CoIYbg82AadUMg3C
- Guest Reservations: https://www.guestreservations.com/raj-resort-patna/booking?A=1

Keep Instagram/Facebook in **Follow Us**, Google Maps in **Directions**, and Justdial in **Other Listings**. Do not mix them into the booking cards. External booking platforms handle their own prices, availability, payment and cancellation terms. Do not present the website as a native booking engine.

## Research caveat
The official site returned HTTP 403 to the research browser, and social profiles could not be reliably inspected. Third-party details may be stale or inconsistent. Confirm all contact details, amenities, room information, policies, event facilities and photo permissions with the resort before publishing.
