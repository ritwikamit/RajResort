# UI/UX Specification

## Navigation
Home, The Resort, Rooms, Events (only if confirmed), Gallery, Contact. Keep “Book a Stay” prominent.

## Home page order
1. Header and navigation
2. Hero with approved image and CTA pair
3. Verified highlights
4. Short resort introduction
5. Confirmed room options
6. Events/banquets only if confirmed
7. Gallery
8. Verified facilities
9. **Book a Stay** with three separate external provider cards
10. Location and Google Maps directions
11. Contact
12. **Follow Us** with Instagram/Facebook
13. **Other Listings** with Justdial
14. Footer and privacy link

## Booking flow
User clicks “Book a Stay”, reaches the dedicated booking section, chooses MakeMyTrip/Agoda/Guest Reservations, and is sent to the selected external provider in a new tab. The official site remains open. No payment or reservation confirmation is processed by this site.

## Contact flow
Call CTA uses the verified phone number. WhatsApp CTA uses the verified WhatsApp number. If a form is added, collect only necessary fields and clearly state it is an enquiry, not a confirmed booking.

## Gallery
Use owner-approved images categorized only where accurate: Exterior, Rooms, Events, Facilities. Accessible lightbox supports keyboard controls and Escape. Do not publish identifiable guests without consent or use third-party photos without permission.

## Mobile
No horizontal overflow at 320 CSS px. Navigation collapses accessibly; booking cards stack vertically; sticky controls must not cover content. Do not place booking, social and directory icons in one undifferentiated row.

## Missing content
Omit unconfirmed room types, facilities, capacities, rates, policies or contact fields rather than guessing.
