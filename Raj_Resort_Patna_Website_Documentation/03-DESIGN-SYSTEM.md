# Design System & Visual Direction

## Direction
Warm, welcoming and premium hospitality. Use strong, real property photography and restrained glassmorphism on selected floating panels, not every surface. The design should represent the actual property rather than look like a generic luxury-hotel template.

## Suggested starting tokens (not official brand colors)
- Forest: `#173C32`
- Emerald: `#2E6554`
- Ivory: `#F7F4ED`
- Sand/gold: `#D9C7A2`
- Charcoal: `#202723`
- Muted text: `#69736C`
- Glass: `rgba(255,255,255,0.14)`
- Glass border: `rgba(255,255,255,0.28)`

Confirm these with the owner and official logo before finalizing.

## Typography
Use a refined serif for headings (e.g. Cormorant Garamond or DM Serif Display) and a readable sans serif for body/UI (e.g. Inter or Manrope). Avoid tiny text and excessive letter spacing.

## Hero
Use an approved high-resolution property image, subtle gradient for text contrast, concise headline, “Book a Stay” primary CTA and “View Gallery” secondary CTA. Keep the subject visible on mobile and avoid overlaying important photo details.

## Glassmorphism rules
Translucent surfaces, backdrop blur, fine borders and soft shadows used sparingly. Maintain contrast, provide an opaque fallback and avoid long paragraphs inside glass panels.

## Components and motion
Moderately rounded cards, clear button states, minimum touch targets around 44×44 CSS px, consistent gallery ratios and distinct booking/social/directions groups. Use subtle opacity/transform motion only; respect reduced-motion settings.

## Accessibility
WCAG AA contrast, visible keyboard focus, logical headings, keyboard-operable navigation/lightbox, descriptive alt text, and no essential copy embedded inside images.
